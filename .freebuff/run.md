# Run Doc — Frontend Preview

## Uncommitted Artifacts

- `frontend/.env.local` — copy procedure: create with `NEXT_PUBLIC_API_URL=http://localhost:8000`
- `frontend/node_modules/` — install via `cd frontend && npm install`

## How to Run the Server

1. `cd frontend`
2. `npm run dev` — Next.js dev server starts on the next available port (default 3000)
3. The server log goes to `.freebuff/preview-*.log`
